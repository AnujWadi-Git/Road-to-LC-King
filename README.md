# Road to LC King

20-day Python coding fluency program ("Python Gym Before LeetCode").
Goal: turn an English requirement into working Python, from a blank file.

- `dayNN/` — exercises and my solutions for each day
- `PROGRESS.md` — daily scores and mastery tracking
- `ERROR_LOG.md` — mistake database, reviewed every day

## VS Code auto-push
Open this folder in VS Code (`code .`). The GitDoc extension commits and pushes `.py`/`.md` changes ~10s after you save.

## The book
`Python_Fluency_Book.pdf` is the one-concept-per-page study book (dark theme). Rebuild with `python3 book/build_book.py` after editing `book/content.py`.
